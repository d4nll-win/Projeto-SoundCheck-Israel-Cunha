# SoundCheck 

**Análise e identificação de problemas técnicos em gravações de áudio.**

## Sobre o projeto

O SoundCheck é um projeto acadêmico desenvolvido como parte do curso de Ciência da Computação.

A ideia surgiu da dificuldade que músicos iniciantes enfrentam ao realizar gravações em home studios, principalmente na identificação de problemas que podem comprometer a qualidade do áudio.

O projeto propõe uma plataforma com uma interface simples e intuitiva, voltada a auxiliar esses usuários durante o processo de análise de suas gravações.

## Objetivos

- Facilitar o acesso a informações sobre qualidade de áudio.
- Auxiliar músicos iniciantes a compreender aspectos técnicos de suas gravações.
- Oferecer uma interface acessível e de fácil utilização.
- Reunir recursos relacionados à experiência de gravação em home studios.

O projeto possui seus arquivos organizados em pastas separadas para facilitar a manutenção e localização dos arquivos.
